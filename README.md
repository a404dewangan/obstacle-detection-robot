# Obstacle Detection Robot 🤖

## Description
An ultrasonic sensor-based obstacle detection robot developed using O2 Labs block-based programming. 
The robot is capable of detecting obstacles in real-time and automatically changing its direction to avoid collisions.

## Features
* Detects obstacles using ultrasonic
* Automatic direction control
* Real-time obstacle avoidance
* Efficient navigation system

## Technologies Used
* O2 Labs Software
* Ultrasonic Sensor 
* Robotics Kit

## How it Works
The robot uses an ultrasonic sensor to measure the distance between itself and nearby objects.
When an obstacle is detected within a certain range, the robot stops and changes direction to avoid collision. 
The decision-making logic is implemented using block-based programming in O2 Labs.

## Applications
* Autonomous robotics
* Smart vehicles
* Industrial automation
* Obstacle avoidance systems
